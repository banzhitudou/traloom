# 日文横排与竖排识别

新建项目仍只需要原书 PDF。“识别设置”是可选项，默认英语；日文可选择横排或竖排。工程建立后，在“设置 → 文字识别”修改默认设置。设置保存在工程里，不依赖本机目录位置。

改变设置不会重识别已经完成的页面，不会覆盖已有原文、译文或识别框。正在自动识别的任务需暂停，再继续才加载新设置。混排页面建议分别框选正文与图注，在补录区域里指定方向；区域选择不改变工程默认设置。

点击“暂停”后，暂停选择保存在工程中。切换到设置、返回工作台或重新打开工程都不会自行恢复，需手动点击“继续识别”。暂停不会中断已经发出的本机 OCR，但不会继续保存下一页。

日文竖排使用 `jpn_vert` 模型，从上到下、列从右到左处理。它不是旋转横排文字，也不自动推断整页混排。第一版竖排整页统一使用栅格 OCR，包括含文字层的 PDF，以避免横排文字层分块破坏竖排列顺序；因此可能比文字层提取更慢。横排优先使用文字层，没有可用文字层时才调用整页 OCR。

文字层含有私用区编码、异常控制符或与日文无关的脚本时，会标记该页的异常字体。使用同一字体的区域（包括表面上像正常字母、实际映射错误的单位）改用局部 OCR，保留坐标和正常字体内容。日文区域使用日文模型，纯数字或拉丁字母区域使用英文模型。局部 OCR 返回空文本时会用另一种分块模式重试；仍为空则保留文字层原文和坐标，将该段标为“存疑”并写入核对备注，继续后续区域和页面，不因单个空结果反复暂停。真正的加载、渲染或 OCR 执行错误仍会暂停。检测是启发式的，并不能识别所有合法字符间的错误映射。

已有段落不会自动重写。可选中段落，进入“调整识别区域”后重新识别，先预览再确认；也可勾选“忽略文字层，使用本机 OCR”。该选项不包含 AI 整理断行的费用，后者仍由其独立开关控制。

数字和单位仍需对照原页复核，尤其大小写。实际目录页测试中，`2.36`、`1.99`、`-0.37` 可恢复，但 `kW` 会被识别成 `kw`；程序不擅自把单位改成预设拼写。

OCR 运行在本机，无模型 API 费用。两个日文模型 gzip 后合计约 3.3 MiB。识别时间与内存消耗随页面尺寸和复杂程度增加，模型不会同时驻留在每个任务中。AI 整理断行和翻译仍是独立的可选模型调用，可能收费。

整理断行保持原文语言：日文文字之间不新增空格，英文片段保留必要空格。OCR 中竖排模型产生的汉字、假名字间伪空格会清理；复杂内容应对照 PDF 核查。

普通印刷体横排与竖排合成样例已做实际离线识别验证，包含识别文本、顺序和边界检查。不代表对所有日文书籍达到相同准确率。振假名、竖排中横排数字或英文、漫画气泡、旧字体、模糊扫描及复杂跨栏需要人工核对；不保证自动分离振假名。
