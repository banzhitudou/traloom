a real publication or a private manuscript. The interface is in Simplified
Chinese; the screenshots do not imply an English UI. Displayed translations
illustrate the workflow and are not publication-ready or a quality benchmark.

No new AI request was made for these captures. No source/translation text was
typed or replaced for staging. Existing edits may be saved by the application's
normal auto-save when navigating. No glossary entries were added, and recognition
settings were not saved or changed. Captures were visually checked for API keys,
local file paths, unrelated project names, and private manuscript content.
