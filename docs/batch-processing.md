# 批量处理

入口：**项目 → 批量处理**。原文识别完成后，新工程会提示一次；选择“稍后再说”后，仍可从项目菜单进入。

两项任务独立运行：

- **整理原文断行**：仅修复当前段中的换行和跨行断词，不跨段合并，不改段号、顺序或 PDF 坐标。保留有意义的标题、列表、诗歌等换行。若模型修改文字或标点，结果会被拦截，原文保持不变。
- **生成译文初稿**：生成一份中文初稿，采用后为待审。选择“设置 → 译文参考”中保存的一个方案，按该方案要求生成初稿；不预设特定读者年龄或文体。建议先整理原文断行，再开始批量翻译。

可选全部符合条件的段落，或按界面上的段落序号输入区间。默认先试 10 段，数量可更改，也可勾选代表性段落。先试同样调用模型，并不免费。每次启动会确认数量、模型和费用风险；不猜测供应商价格。

试处理结果不会自动修改原文或译文。看对照后，可以逐段采用、全部采用或逐段放弃。满意后继续剩余段落，正式处理结果逐段保存。采用过的段落不重复调用。默认跳过任何已有译文，包括待译状态但已有文本的段落；空原文也跳过。没有换行或已整理且未再变化的原文不重复整理。

运行中的任务可以暂停或取消。暂停不强行中止正在发送的请求，当前请求可能完成并产生费用，但不会继续发起新请求；取消不撤销已采用的结果。关闭批量窗口不会停止后台任务；退出整个程序会中断运行。队列、候选和处理结果保存在 `.twproj` 中。重新打开后，可从“继续之前的任务”恢复。

失败项不覆盖稿件。连续三段失败会暂停，避免继续产生费用。重试前提示可能再次计费。异常退出、网络超时或工程切换时，结果未知的请求不会自动重试。写入结果前重新核对原文、译文、状态和段落身份，发生变化就跳过，避免覆盖手工修改。

已有译文没有批量覆盖入口。整理和生成、采用操作均保留修订记录，可以在“备注与记录”查看历史与恢复版本。请先用少量代表性正文试处理，再扩大范围。

测试使用合成工程和本地假模型，不需要私人书稿或实际模型费用。运行 `npm test` 检查纯逻辑，`tests/batch-processing.runtime.ts` 在 Electron 的 Node 模式下检查 SQLite 队列和防覆盖行为；`tests/batch-desktop.runtime.cjs` 提供独立内存工程界面验收窗口。
