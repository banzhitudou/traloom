# Traloom 0.2.4

本次为旋转文字识别框修复预览版，延续 0.2.3 的安全加固。

## 修复

- PDF 文字层识别框跟随文字方向，修正 90°、180°、270° 旋转文字的宽高与位置。
- 多行分块沿文字自身的阅读方向合并，保留提取文字。
- 完整应用 PDF 页面变换矩阵，并正确裁剪超出页面的识别框。
- 已有工程的旧识别框不会自动迁移，也不会自动重识别或修改译文。

## 下载

- `Traloom-0.2.4-macOS-arm64.dmg`：Apple Silicon Mac（M 系列）。没有 Intel Mac 或 Windows 发行包。
- 两份《A World of Cats》原创 AI 辅助示例 PDF：单页版和跨页版，供新建工程、复杂版面和旋转文字测试。不是正式出版物或兽医建议，不包含翻译工程或密钥。
- `SHA256SUMS.txt`：安装包和示例 PDF 的校验值。

当前仍为预览版，采用临时签名，未完成 Apple Developer ID 签名及公证。安装前请退出程序并手动备份 `.twproj` 工程。

## 验证

- 38 组、163 项单元测试通过。
- TypeScript 检查和生产构建通过。
- 沙箱环境中的实际 OCR、PDF 渲染与旋转文字识别框测试通过；测试 PDF 的识别框覆盖全部文字像素。

示例说明见 [docs/demo-pdfs.md](https://github.com/banzhitudou/traloom/blob/main/docs/demo-pdfs.md)。
