# Traloom 0.3.1 Preview

从一本 PDF，到一份可以交付的中文译稿。

## 英语和日语都支持，不是日语专用版

| 功能 | 当前范围 |
| --- | --- |
| 内置英语 OCR | 英语印刷体横排，`eng`，仍为默认识别设置 |
| 内置日语 OCR | 日文印刷体横排 `jpn`、竖排 `jpn_vert`，需选择对应方向 |
| PDF 文字层提取 | 读取已有文字，独立于 OCR 模型；受字体编码、文字层及版面质量影响 |
| AI 视觉识别（测试） | 可尝试英语、日语等原文；实际语言能力取决于所选图片模型，需要上传图像，可能收费 |

英语和日语的内置 OCR 都在本机运行，无需模型 API；其他扫描语言的本机 OCR 模型目前未内置。不保证手写字、振假名、复杂混排或模糊扫描的准确率。原文识别语言不等于译文目标语言：当前 AI 译文目标仍为简体中文。

## 这一版有什么新变化

- 重写中英文首页，按实际翻译工作流程介绍 PDF 对照、术语统一、审校与出版交接。
- 批量整理原文断行、生成中文初稿：支持范围、小批量试处理、预览采用、暂停继续及已有译文保护。
- 译文参考方案可编辑、分别保存、恢复默认要求；批量初稿可选用已保存方案。
- 支持为 AI 整理断行和视觉识别单独指定模型；段落增加待译与待审状态入口。
- 在已有英语横排 OCR 基础上，新增日文横排、竖排 OCR；改进异常文字层的恢复，识别暂停状态不会因切换界面自动恢复。
- 支持恢复有原始记录的识别原文，保留译文与段号；不支持的合并段等会跳过。
- 新增 AI 区域视觉识别、整页识别与分块预览（测试），保留上传确认、费用说明、候选记录及人工采用步骤。
- 整页识别增加定位网格、分区阅读顺序要求及保守的 PDF 文字层边界校准。

## 安装与示例

- `Traloom-0.3.1-macOS-arm64.dmg`：Apple Silicon Mac 预览安装包。
- `A_World_of_Cats_Traloom_Demo_Single_Pages.pdf`：猫主题原创演示资料，单页版。
- `A_World_of_Cats_Traloom_Demo_Spreads.pdf`：同一演示资料的跨页版。
- `SHA256SUMS.txt`：上述附件的 SHA-256 校验值。

两份猫示例都是英语资料，可用于体验英语原文提取和英语图像文字 OCR，不是日文识别样本。下载一个示例 PDF，在程序中“新建项目”后选择它即可练习。示例不含私人译稿、工程或模型配置。内容是软件演示材料，不是正式出版物或兽医建议；软件 MIT 许可不自动授予 PDF 内容及第三方字体的使用权。

安装包采用临时签名，未经过 Apple Developer ID 签名和公证，macOS 可能显示安全或钥匙串授权提示。当前仅发布 Apple Silicon Mac 安装包；Windows 发行包尚未独立验证。

## 重要限制与数据保护

这是预览版，界面主要为简体中文，译文目标目前为简体中文。AI 服务需用户自行配置，可能收费；使用时会将相应文本、上下文、术语或图像发送到所配置服务。本地保存不等于 AI 离线。

**AI 视觉识别与整页分块仍不完善。** 真实测试中仍出现日文错字、边界偏移、区域重叠及阅读顺序问题；越界或截断结果会被拒绝。不得未经核对就对整本书自动采用。

已有翻译段或识别记录的页面只允许整页对照预览，禁止覆盖式重分块。空白待识别页也需要逐页确认才写入。既有工程不会因升级而自动重识别。

更新或测试前，请退出程序后手动复制 `.twproj` 备份。旧工程如依赖外部 PDF，应一并保留。不要将私人书稿或工程上传到公开仓库。

## English Summary

Traloom supports both English and Japanese source recognition, not Japanese alone. Bundled offline OCR uses `eng` for horizontal printed English (still the default), `jpn` for horizontal printed Japanese, and `jpn_vert` for vertical printed Japanese. Other local OCR languages are not bundled. PDF text extraction reads an existing text layer and is not limited by these OCR model choices, but depends on font encoding and layout. AI vision language support depends on the configured image-capable model; image uploads may incur fees. AI translation currently targets Simplified Chinese.

This preview extends the existing English OCR with Japanese horizontal/vertical recognition, alongside resumable batch cleanup and draft translation, editable reference profiles, original-recognition recovery, and experimental region/page vision OCR. It also refreshes the Chinese and English project introductions. Both attached cat-themed PDFs are English-language demo materials, not Japanese OCR samples.

Whole-page OCR remains experimental: incorrect text, boxes, overlap, and reading order are still possible. Existing recognized pages are comparison-only and cannot be overwritten. AI requests require your provider configuration and may incur fees. Back up projects before updating.

The DMG is for Apple Silicon macOS, ad-hoc signed and not notarized. Both original cat-themed demo PDFs are attached. The software license does not license demo content or third-party fonts.
