# Security

Traloom is an early-stage desktop application. Security fixes target the latest source version; no long-term support policy is currently offered.

## Reporting A Vulnerability

Do not disclose API keys, manuscripts, project databases, or exploit details in public issues.

If the GitHub repository offers private vulnerability reporting under its Security tab, use that channel. If it is not enabled, open an issue asking for a private reporting channel without including sensitive details, and wait for a maintainer to provide one.

Include the affected version, operating system, a minimal reproduction with synthetic data, and the potential impact. Remove credentials and personal information.

## Handling Project Files

Treat `.twproj` files and exported documents as private data. They may contain a complete PDF, translations, notes, revision history, and model configuration. Do not publish them as debugging attachments.

AI requests are sent to the endpoint configured by the user. Use trusted providers and review their data policies. Avoid entering credentials or confidential material into untrusted projects or services.
