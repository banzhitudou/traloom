# Traloom

[English](README.en.md) | 简体中文

**AI 辅助，译者精修。**

读作 tra-LOOM，近似“特拉卢姆”，重音在后一个音节。名字结合 Translation 与 Loom，表达由译者精修、编织语言的工作方式。

面向图书翻译的本地桌面工作台，支持 PDF 对照、段落译文编辑、项目术语、备注、修订记录，以及 DOCX 和 HTML 导出。AI 功能由用户配置模型服务。

## 功能

- 从一本 PDF 建立工程，提取文字层或进行本地 OCR。
- 对照 PDF 逐段编辑译文，调整识别区域，排序、合并和拆分翻译段。
- 手工维护术语，检查全书译名一致性，预览后逐处或批量替换。
- 用待译、待审、存疑和通过状态组织审校工作。
- 保存段落备注、项目备注和修订记录。
- 自行配置模型服务及 1–5 个译文参考方案，不限定翻译文风。
- 导出 DOCX 表格或段落稿，以及可切换中文、原文和双语的 HTML 预览。
- 用单个 `.twproj` 工程携带 PDF 和翻译数据，新工程可以移动后重新打开。

## 开始使用

当前版本为早期版本，主要在 Apple Silicon macOS 上验证，界面以简体中文为主。Windows 提供构建配置，但发行包尚需独立验证。目前没有已发布的正式下载链接。

1. 按下方开发说明启动，或自行构建应用。
2. 新建项目并选择 PDF。工程会生成在 PDF 所在文件夹，不覆盖原书。
3. 核对识别出的段落和区域，在 PDF 旁编辑译文。
4. 如需 AI 参考，在“设置”中配置模型服务及译文参考要求。
5. 完成审校后，在“导出”中选择格式、页面范围和备注选项。

有文字层的 PDF 可提取其他语言；随应用内置的 OCR 模型目前仅支持英文。扫描件、复杂版面和 AI 译文均需要人工核对。

## 数据与隐私

工程数据保存在本机，但启用 AI 功能时，会将相应文本和上下文发送至用户配置的模型服务。模型费用及数据处理政策由该服务决定，不应把“本地工程”理解为所有功能都离线运行。

工程文件可能包含受版权保护的原书、私人译文、备注和模型配置，不要上传到公开仓库。软件的 MIT 许可证不授予书稿或用户导入资料的使用权。

## 开发

需要 Node.js 22 或更新的受支持版本，以及 npm。首次安装会为 Electron 构建 SQLite 原生模块；部分平台需要本机编译工具。

```sh
npm ci
npm run dev
```

开发版使用独立的 `translation-workbench-dev` 应用数据目录。首次启动会显示项目选择页。测试自己的书稿时，请打开工程副本。

```sh
npm test
npm run typecheck
npm run build
```

测试数据由测试代码生成，不需要任何真实书稿或外部人名、地名词典。

## 打包

```sh
npm run build:mac
npm run build:win
```

在 Apple Silicon Mac 上，可用 `npm run package:mac:local` 生成本地测试应用，输出到 `dist/local/`。本地构建采用临时签名，公开发布仍需完成对应平台的签名、公证与发行验证。

## 项目数据

新建项目只需选择原书 PDF。工作台优先读取 PDF 文字层；没有文字层的页面使用随程序内置的英文 OCR 模型识别。识别按页保存，可以暂停、恢复，不会覆盖已有译文。复杂版面仍需人工核对识别和段落分块。

译文参考的数量（1 至 5 条）和翻译要求在“设置 → 译文参考”中统一设置，对当前工程全部段落生效，默认一条，无固定文风。术语仅提供手工建立，保留人名、地名等分类以及离线词典。新建界面不提供 MinerU、已有译稿或风格指南入口。

`.twproj` 保存译文、术语、备注、修订记录和模型配置等私人数据。新建工程直接生成在原书 PDF 所在文件夹，命名为 `原文件名-翻译工程.twproj`；同名文件存在时另加序号，不会覆盖。文件内嵌 PDF、识别 JSON/Markdown 和导入资源，可以仅移动 `.twproj` 后重新打开，不需要外部资源文件夹。工程内资源带 SHA-256 校验。

旧版绝对路径工程继续兼容，不会自动重识别。PDF 缺失时，预览区提供重新关联入口。旧工程中的人名库、地名库、项目文档和助手历史数据保留，但不再提供独立功能入口。换电脑后可能需要重新填写模型 API 密钥。

主导航收敛为项目、术语、备注与记录、搜索、导出、设置。项目菜单包含切换项目和项目资料；备注与记录包含全书备注和修订历史。段落顶部可直接调用 AI 整理断行，预览后确认保存，不自动覆盖原文。

不自动创建备份。手动备份前先退出程序，确保工程已保存并完成数据库日志合并，再复制 `.twproj` 文件。需要恢复时，在项目选择页面点击“打开项目文件”，选择备份工程即可。新建工程包含原书 PDF；旧工程如果仍依赖外部 PDF，应同时保留 PDF。

“设置 → 译文参考”可选择 1–5 个方案。“默认”方案的翻译要求为空，其余方案分别填写名称与翻译要求；生成时按方案顺序返回，结果使用用户设置的名称。

产品名为 Traloom，安装包名称为 `Traloom.app`。为兼容已有工程，安装版保留 `translation-workbench` 数据目录、原应用标识与 `.twproj` 工程后缀。源码、应用安装包和用户书稿应分别管理。不要将工程、真实原书、导出成品或服务密钥提交到代码仓库。
